## Brand Capital Index (BCI) Methodology Whitepaper — v1.0

First public release of the BCI methodology — an open, three-dimensional brand valuation framework.

### What's inside
- `BCI-Whitepaper-v1.0.pdf` — Full methodology (≈9 pages)
- `README.md` — Quick overview + formula
- `CITATION.cff` — Machine-readable citation
- `LICENSE` — CC BY-NC-SA 4.0
- `CHANGELOG.md` — Version history

### Formula
```
BCI = α · FBV + β · SCV + γ · AIV    (α + β + γ = 1, BCI ∈ [0,100])
```

- **FBV** — Financial Brand Value (ISO 10668 income approach)
- **SCV** — Sustainability Compliance Value (ISSB / TNFD / CSRD aligned)
- **AIV** — AI Visibility Value (ChatGPT / Gemini / Perplexity / Claude)

### Preliminary validation
30 Taiwan-listed companies, 2024-2025 quarterly data. BCI explains 15-20% more subsequent revenue variation than single-dimension FBV.

### Citation

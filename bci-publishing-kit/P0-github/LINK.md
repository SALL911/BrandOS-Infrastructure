# GitHub — 直達連結

## 主要頁面
- **Repo (建立新 repo)**: https://github.com/new
- **Repo 命名**: `symcio-bci-methodology`
- **預期 Repo URL**: https://github.com/sall911/symcio-bci-methodology

## 操作頁面
- 建立 Release: https://github.com/sall911/symcio-bci-methodology/releases/new
- 設定 Topics: https://github.com/sall911/symcio-bci-methodology/settings
- 啟用 GitHub Pages: https://github.com/sall911/symcio-bci-methodology/settings/pages
- 連結 Zenodo: https://zenodo.org/account/settings/github/

## 為什麼 P0
GitHub commit timestamp = 法律承認的著作權「公開發表時間戳」。Zenodo DOI 也必須從 GitHub Release 觸發產生。所有後續平台都會引用這個 repo URL。

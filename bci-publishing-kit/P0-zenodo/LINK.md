# Zenodo — 直達連結

## 主要頁面
- **註冊 / 登入（用 GitHub 一鍵登入）**: https://zenodo.org/signup/
- **GitHub 連結頁（最關鍵）**: https://zenodo.org/account/settings/github/
- **手動上傳（備案）**: https://zenodo.org/uploads/new

## 操作頁面
- 我的上傳: https://zenodo.org/me/uploads
- 編輯 metadata: 上傳後的 record edit URL（建立後產生）
- ORCID 連結: https://zenodo.org/account/settings/linkedaccounts/

## 為什麼 P0
Zenodo DOI = **學術界的身分證號碼**。
- 所有後續平台引用都指向同一個 DOI → 引用聚合
- Google Scholar 透過 DOI 追蹤引用次數
- Zenodo 由 CERN 維運，DOI 永久不失效
- 與 GitHub 整合：每次發 Release 自動產生新版本 DOI

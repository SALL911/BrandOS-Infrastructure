# Medium — 操作步驟（15 分鐘）

## 步驟

### 1. 註冊 + Profile (3 分鐘)
1. https://medium.com/m/signin
2. 用 Google / Email 註冊
3. Profile 設定:
   - Name: Chih-Chuan Huang
   - Short bio (160 chars): 從 `_assets/author-bio.md` 取英文版
   - 加 social links: GitHub / LinkedIn / ORCID

### 2. 寫文章 (10 分鐘)
1. https://medium.com/new-story
2. **標題**: `Beyond Interbrand: Why Brand Valuation Needs a Three-Dimensional Framework`
3. **副標題**: `Introducing the Brand Capital Index (BCI) — an open methodology integrating ISO 10668, ESG compliance, and AI visibility.`
4. **內文**: 從 `SUBMIT.md` 複製貼上（已準備好的 1500-2000 字英文版）
5. **嵌入元素**:
   - BCI 公式（用 code block）
   - 一張 hero image
   - 引用 ISO 10668 / ISSB / TNFD（超連結到官方頁面）
6. **底部 CTA**:
   ```
   📄 SSRN paper: [SSRN_URL]
   💾 Zenodo DOI: https://doi.org/10.5281/zenodo.XXXXXXXX
   🛠 GitHub: https://github.com/sall911/symcio-bci-methodology
   👤 ORCID: https://orcid.org/0009-0004-6472-4566
   ```

### 3. Tags 設定 (1 分鐘)
最多 5 個（SEO 關鍵）:
- `Brand Valuation`
- `ESG`
- `AI`
- `Sustainability`
- `Marketing Strategy`

### 4. SEO 設定 (1 分鐘)
1. 三點選單 → **More settings**
2. **SEO Title**: `Brand Capital Index (BCI): Three-Dimensional Brand Valuation`
3. **SEO Description**: 從 `_assets/abstract-en.md` 取前 155 字
4. **Customize Friend Link**: 啟用（之後可分享給非訂閱者）

### 5. Publish + 跨平台同步 (2 分鐘)
1. **Publish**
2. 取得 canonical URL（複製）
3. 回 GitHub README.md 加上「Read on Medium」連結
4. 在 LinkedIn Article 的 CTA 區加上 Medium 連結
5. 轉發到 X/Twitter（如有）

### 6. 投稿到 Publications（可選）
1. 文章 publish 後 → 三點 → **Submit to a publication**
2. 投 **DataDrivenInvestor** 或 **Better Marketing**
3. 編輯通過後會出現在該 publication，觸及大幅放大

## 驗收
- [ ] Story 顯示 5 個 tags
- [ ] Friend Link 可用
- [ ] Google 在 1 週內索引（site:medium.com "Brand Capital Index"）
- [ ] Read time 顯示 7-9 分鐘

## 預估時間
**15 分鐘**

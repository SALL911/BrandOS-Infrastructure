# ORCID — 操作步驟（10 分鐘）

## 前置
- [ ] Zenodo DOI 已產生
- [ ] SSRN 投稿（通過審核更佳）

## 步驟

### 1. 登入 + 更新 Profile (3 分鐘)
1. 開 https://orcid.org/my-orcid
2. **Biography**: 貼入 SUBMIT.md 的自我介紹
3. **Employment**: 加入 Symcio Co., Ltd.
4. **Keywords**: 加入 7 個關鍵字
5. **Websites & social links**:
   - https://symcio.tw
   - https://github.com/sall911
6. Save

### 2. 連結 Zenodo（自動匯入）(3 分鐘)
1. https://orcid.org/my-orcid#works
2. **Add works** → **Search & link** → 選 **DataCite**
3. 授權 DataCite 寫入你的 ORCID
4. 系統自動列出所有以你 ORCID 提交的 Zenodo records
5. 勾選 BCI 白皮書 → **Import works**

### 3. 連結 Crossref（如有 DOI 上線）(2 分鐘)
1. 同上 **Search & link** → **Crossref Metadata Search**
2. 搜 "Brand Capital Index"
3. Import

### 4. 設定 Trusted Organizations (2 分鐘)
1. https://orcid.org/account#trusted-orgs
2. 授權: Zenodo, DataCite, Crossref → 未來自動同步

## 驗收
- [ ] Works 列表至少有 1 筆 BCI 白皮書
- [ ] 點進 work 顯示完整 metadata（含 DOI）
- [ ] Profile 顯示 Employment + Biography
- [ ] Visibility 設為 "Everyone"（公開）

## 預估時間
**10 分鐘**

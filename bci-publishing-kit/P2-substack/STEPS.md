# Substack — 操作步驟（20 分鐘）

1. 註冊: https://substack.com/signup
2. 建 Publication: https://substack.com/dashboard/new
3. 設定基本資料（從 SUBMIT.md 的 Publication 設定區塊）
4. 上傳 Logo + 設定 colors
5. **New post** → 貼第一期內容
6. 設定 **Welcome email**
7. **Publish**
8. 把 Substack URL 加到所有平台的 Bio / Author Page

## 引流策略
- LinkedIn / Medium 文章底部加「Subscribe to BCI Weekly」按鈕（嵌入 Substack subscribe form）
- ORCID Profile 加 Substack URL
- GitHub README 加訂閱 badge

**預估**: 20 分鐘

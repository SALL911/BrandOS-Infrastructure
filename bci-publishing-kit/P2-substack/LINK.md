# Substack — 直達連結

## 主要頁面
- **註冊**: https://substack.com/signup
- **建立新 Publication**: https://substack.com/dashboard/new
- **撰寫新貼文**: 進到你的 Publication → "New post"

## 推薦 Publication 設定
- **URL**: `bci.substack.com` 或 `symcio.substack.com`
- **Name**: `Brand Capital Index Weekly` (or `Symcio Research`)

## 為什麼 P2
- 訂閱制長期讀者經營
- 每篇自動寄信給所有訂閱者（綁住受眾）
- SEO 友善（公開頁面 Google 都索引）
- 可導出訂閱名單到 CRM
- 未來 BCI 更新、產業分析都從這裡發

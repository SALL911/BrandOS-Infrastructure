> **Brand Capital Index (BCI) Methodology Whitepaper v1.0**
> A three-dimensional, open-methodology brand valuation framework integrating ISO 10668 Financial Brand Value, Sustainability Compliance Value, and AI Visibility Value.
>
> By **Chih-Chuan Huang** · Symcio Co., Ltd. · April 2026

---

## TL;DR

```
BCI = α · FBV + β · SCV + γ · AIV     (α + β + γ = 1, BCI ∈ [0, 100])
```

- **FBV** — Financial Brand Value (ISO 10668:2010 income approach)
- **SCV** — Sustainability Compliance Value (ISSB / TNFD / CSRD aligned, regulation-neutral)
- **AIV** — AI Visibility Value (ChatGPT / Gemini / Perplexity / Claude cross-engine)

2026 baseline weights: α=0.50, β=0.25, γ=0.25 · projected 2030: α=0.35, β=0.35, γ=0.30.

Preliminary validation on 30 Taiwan-listed companies (2024–2025): BCI explains **15–20% more subsequent revenue variation** than single-dimension FBV.

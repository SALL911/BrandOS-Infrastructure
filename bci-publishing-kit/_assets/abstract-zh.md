# 摘要 — 繁體中文 (300 字)

本白皮書提出**品牌資本指數**（Brand Capital Index, BCI），一個將品牌估值從傳統單維度（財務貢獻）擴展為三維時序指標的開放方法論。

BCI 公式為:

```
BCI = α·FBV + β·SCV + γ·AIV    （α + β + γ = 1，BCI ∈ [0,100]）
```

三個維度分別為:
- **FBV (Financial Brand Value)** — 依循 ISO 10668:2010 所得法計算品牌對企業盈餘的財務貢獻
- **SCV (Sustainability Compliance Value)** — 整合 ISSB S1/S2、TNFD、歐盟 CSRD、台灣金管會 ESG 揭露要求等法規風險的合規價值
- **AIV (AI Visibility Value)** — 跨 ChatGPT / Gemini / Perplexity / Claude 四引擎的品牌引用率與位置分數

BCI 解決傳統估值的兩個結構性盲點:(1) 強制性永續法規已成為市場准入決定因素;(2) 生成式 AI 平台已成為消費者品牌發現的主要管道(2025 年滲透率 >30%)。

以 30 家台灣上市櫃公司為樣本的初步驗證顯示,BCI 對後續營收變異的解釋力較單維度 FBV 高 15-20%,並能提早 1-2 季偵測到品牌資本減損訊號。

本方法論為開放標準（CC BY-NC-SA 4.0），設計為全球適用、法規中立,並建立配套治理架構（權重校準、稽核軌跡、版本控管）。

**關鍵字**: 品牌估值、ISO 10668、ESG 合規、AI 可見度、生成式引擎優化、品牌治理、ISSB、TNFD

# arXiv — 操作步驟（30 分鐘 + endorsement 等待）

> ⚠️ 如沒有 endorser，**跳過此平台**。SSRN 已涵蓋金融學術社群觸及。

## 步驟

### 1. 註冊 (3 分鐘)
- https://arxiv.org/user/register
- 用學術 email（gmail 也可，但通過率較低）
- 確認 email

### 2. 申請 Endorsement (等 1-7 天)
1. 開 https://arxiv.org/auth/need-endorsement
2. 選 category: `q-fin.GN`
3. 系統會給你一個 endorsement code
4. **找 endorser**（任何在 q-fin 發過論文的學者）:
   - 從 SSRN / Google Scholar 找熟識的學者
   - 寫信附上你的 code + 白皮書 PDF + 自我介紹
5. 對方輸入 code 後即可 endorse 你

### 3. 投稿 (15 分鐘)
- https://arxiv.org/submit
- 上傳 PDF (注意: 必須 LaTeX source 或符合格式的 PDF)
- 填 metadata（從 SUBMIT.md）
- Submit

### 4. 等審核 (1-3 工作天)
- arXiv moderator 檢查格式 + 主題分類是否正確
- 通過後 email 通知 arXiv ID（格式: 2604.XXXXX）

## 替代方案
若無法取得 endorsement，**改投** SSRN（已在 P0 完成）+ ResearchGate（已在 P1 完成）即可。對學術觸及效果差距不大。

**預估**: 30 分鐘 + endorsement 1-7 天

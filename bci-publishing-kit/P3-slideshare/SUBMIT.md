```
For 38 years, brand valuation has been one-dimensional.
That worked when ISO 10668 was drafted in 2010.

```
**視覺**: Interbrand 1988-2026 時間軸

### Slide 3-4：兩個結構性盲點
- Slide 3: CSRD / ESPR / CBAM / 金管會 — 永續法規已成市場准入門檻
- Slide 4: 30% 消費者先問 AI 才開 Google — 生成式 AI 已成發現主管道

### Slide 5：BCI 公式
```
BCI = α · FBV + β · SCV + γ · AIV

α + β + γ = 1.00
BCI ∈ [0, 100]
```
**視覺**: 大字 monospace + 三個彩色 chip

### Slide 6：FBV — Financial Brand Value
- ISO 10668 income approach
- 品牌營收 × 品牌角色指數 × 品牌強度 ÷ 折現率
- 10 個強度因子

### Slide 7：SCV — Sustainability Compliance Value
- SCV = 0.40·RCS + 0.40·EDS + 0.20·NCS
- ISSB S1/S2 + TNFD + CSRD aligned
- 法規中立

### Slide 8：AIV — AI Visibility Value
- 跨 ChatGPT 0.35 / Perplexity 0.25 / Google AI 0.25 / Claude 0.15
- Citation rate × Position score

### Slide 9：權重校準
- 2026 baseline: α=0.50 β=0.25 γ=0.25
- 2030 projected: α=0.35 β=0.35 γ=0.30
- 隨永續法規 + AI 滲透率調整

### Slide 10：初步驗證
- 30 家台股 / 10 產業
- 三維 vs 單維: +15-20% 後續營收解釋力
- FBV ↔ SCV r=0.31（弱）→ 永續是獨立維度

### Slide 11：治理架構
- 權重校準程序
- 稽核軌跡（Git 版控）
- 版本控管（CITATION.cff / Zenodo DOI）

### Slide 12：限制
- 初步樣本限台灣
- AIV 量測週期 = 季度
- 法規時間延遲

### Slide 13：應用場景
- 投資決策（PE / 上市公司）
- 品牌治理（CMO / CSO）
- 政策制定（金管會 / 永續會）

### Slide 14：結論
- BCI 擴展 ISO 10668，不取代
- 法規中立、全球適用、開放方法論
- v1.0 = 邀請學術 + 產業共同驗證

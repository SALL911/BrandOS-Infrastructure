# Speaker Deck — 操作步驟（20 分鐘 + 簡報製作）

## 前置
- [ ] 用 PowerPoint / Keynote / Google Slides 做出 15 頁簡報（依 SUBMIT.md 結構）
- [ ] 或請 Claude / GPT 用 SUBMIT.md 內容產出 PPTX
- [ ] 輸出為 PDF（Speaker Deck 接受 PDF / PPT）

## 步驟

### 1. 註冊 + 上傳 (5 分鐘)
1. https://speakerdeck.com/signup（用 GitHub OAuth）
2. 上傳 PDF
3. 填 Title / Description / Tags（從 SUBMIT.md）
4. License: CC BY-NC-SA 4.0
5. **Publish**

### 2. 取得 embed code (1 分鐘)
- 上傳完成後，每頁簡報下方有 Share 按鈕
- 複製 embed code

### 3. 嵌入到其他平台 (10 分鐘)
- **Medium 文章**: 在 Medium 編輯器貼 Speaker Deck URL → 自動 embed
- **LinkedIn Article**: 加 embed code
- **GitHub README**: 加 Speaker Deck cover image + 連結

### 4. SlideShare 備案版（可選，5 分鐘）
1. https://www.slideshare.net/upload
2. 用 LinkedIn 帳號登入
3. 上傳同份 PDF
4. 雙平台都有，SEO 雙重收錄

## 驗收
- [ ] Speaker Deck 顯示 15 頁
- [ ] Description 含 SSRN / Zenodo / GitHub 連結
- [ ] Medium 文章 embed 後可瀏覽簡報

**預估**: 20 分鐘（不含簡報製作時間）

# Airiti — 操作步驟（30 分鐘，等回信）

1. 註冊個人會員: https://www.airitilibrary.com/User/Register
2. 寫信給 service@airiti.com（用 SUBMIT.md 範本）
3. 附 PDF 白皮書
4. **等回信**（通常 3-7 工作天）

## 後續可能路徑
- Airiti 同意 → 給你投稿後台連結 → 上傳 PDF + 填繁中元資料
- Airiti 拒絕（獨立研究無法直收）→ 改透過合作期刊（如《管理學報》、《中山管理評論》）投稿正式論文版本
- Airiti 介紹合作管道 → 跟進

> 此平台屬「長線經營」，先寄信即可，**不影響整體 30 天發表計畫的關鍵路徑**。

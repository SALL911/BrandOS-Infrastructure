# 華藝線上圖書館 (Airiti Library) — 直達連結

## 主要頁面
- **首頁**: https://www.airitilibrary.com/
- **個人會員註冊**: https://www.airitilibrary.com/User/Register
- **作者投稿說明**: https://service.airiti.com/airitilibrary/
- **投稿信箱**: service@airiti.com

## 為什麼 P3
- **台灣最大中文學術資料庫**
- 台灣學者、研究生、政策研究者主用
- 大學 / 政府機構訂閱基數高，曝光度可觀
- 但**不是「自助投稿」平台**，需透過學校 / 機構 / 出版社 / 自行聯繫 Airiti

## 投稿管道
1. **透過期刊或研討會**（Airiti 收錄該刊物）
2. **機構合作**（大學圖書館 / 研究機構打包提交）
3. **直接聯繫 Airiti**: 寫信給 service@airiti.com 詢問獨立論文收錄方式

> 對獨立研究者而言，這個平台難度較高。可先做為「未來投稿」目標。

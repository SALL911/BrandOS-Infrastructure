# ResearchGate — 操作步驟（15 分鐘）

## 步驟

### 1. 註冊 (5 分鐘)
1. https://www.researchgate.net/signup
2. 選 **Independent Researcher**（如果無大學 affiliation）
3. 填:
   - First / Last name: Chih-Chuan / Huang
   - Institution: Symcio Co., Ltd.
   - Position: Founder / Independent Researcher
   - Email: cchuan911@gmail.com（建議用學術 email 較易通過）
4. 上傳大頭照 + bio（從 `_assets/author-bio.md`）
5. 連結 ORCID: https://www.researchgate.net/account.SettingsLinkedAccountsAccount.html

### 2. Add Publication (5 分鐘)
1. https://www.researchgate.net/publication/add
2. 選 **Add new** → **Working paper**
3. 上傳 PDF
4. ResearchGate 會自動抓 metadata，**確認 + 補完** Title / Authors / Date / DOI
5. 貼入 Abstract（從 SUBMIT.md，300 字版本）
6. 選 Disciplines（勾 3-5 個）
7. **Publish**

### 3. Create Project (3 分鐘)
1. https://www.researchgate.net/project/new
2. Name: `Brand Capital Index (BCI)`
3. Description: 複製 SUBMIT.md 的 Project Description
4. **Add publication** → 選剛上傳的白皮書
5. **Create**

### 4. 追蹤領域 + 推播 (2 分鐘)
1. Topics 頁面 follow: Brand Valuation / ESG / AI in Marketing / Sustainability Reporting
2. Skills & Expertise → 加上: Brand Valuation, ISO 10668, ESG, AI Visibility, Generative AI

## 驗收

- [ ] Project 創建並掛上 publication
- [ ] ORCID 連結成功
- [ ] 1 週後檢查 "Reads" / "Citations" 開始累積

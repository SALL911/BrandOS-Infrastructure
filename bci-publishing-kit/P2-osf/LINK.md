# OSF (Open Science Framework) — 直達連結

## 主要頁面
- **註冊 / 登入**: https://osf.io/login/
- **Dashboard**: https://osf.io/dashboard/
- **建立新 Project**: https://osf.io/myprojects/
- **註冊 ORCID 登入**: https://osf.io/login/?next=/dashboard/

## 為什麼 P2
- 開放科學旗艦平台（Center for Open Science 維運）
- 可放白皮書 + 數據集 + 程式碼一站
- 內建 DOI 註冊（備用引用來源）
- 與 GitHub / Dropbox / Zotero 整合

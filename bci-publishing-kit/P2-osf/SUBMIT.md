```
Brand Capital Index (BCI) — Open Methodology Research
```

## Description
```
The Brand Capital Index (BCI) is an open research project developing a three-dimensional brand valuation framework that integrates ISO 10668 financial value, sustainability compliance value, and AI visibility value. This OSF project hosts the methodology whitepaper, validation datasets, calculation scripts, and version history for independent replication and extension.

Key resources:
- Methodology whitepaper (PDF, v1.0)
- 30-firm Taiwan validation dataset (anonymized)
- Reference implementation (Python)
- Weight calibration documentation

Author: Chih-Chuan Huang (ORCID: 0009-0004-6472-4566), Symcio Co., Ltd.
License: CC BY-NC-SA 4.0
Related publications: Zenodo DOI, SSRN
```

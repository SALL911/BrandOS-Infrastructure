# OSF — 操作步驟（15 分鐘）

1. 註冊（用 ORCID 登入）: https://osf.io/login/
2. Dashboard → **Create new project**
3. 填 Title / Description（從 SUBMIT.md）
4. 加 3 個 Components（Whitepaper / Dataset / Software）
5. 在每個 Component 上傳對應檔案
6. Settings → **Make public**
7. Settings → **Create DOI**
8. 取得 OSF DOI 後，加到 ORCID Works

**預估**: 15 分鐘
